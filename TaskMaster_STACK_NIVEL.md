# TaskMaster — Stack y nivel académico

**Rol:** referencia humana no normativa. Las versiones y dependencias obligatorias están únicamente en `TaskMaster_ESPECIFICACION_CANONICA.md`.

## Nivel esperado

- Java y XML Views;
- `AppCompatActivity` y ciclo de vida básico;
- `findViewById()`, listeners, Intent y extras;
- formularios, validaciones, `Toast`, errores de campo y diálogo de confirmación;
- `SharedPreferences` para un solo perfil;
- `ArrayList` para datos temporales;
- `RecyclerView`, Adapter, ViewHolder y CardView;
- clases, constructores, atributos, getters y métodos pequeños;
- Gradle Groovy, catálogo de versiones y Git.

## Fuera del nivel autorizado

- Kotlin o Compose;
- Fragments, ViewModel o arquitectura por capas;
- Room, SQLite, Firebase, JSON, API o backend;
- servicios, inyección de dependencias o librerías adicionales;
- mecanismos para persistir o restaurar tareas.

La implementación debe mantenerse simple y demostrable dentro de Unidad I. Este archivo no puede modificar el stack congelado del canon.
