# TaskMaster — Alcance académico

**Rol:** resumen humano no normativo. Los detalles obligatorios están únicamente en `TaskMaster_ESPECIFICACION_CANONICA.md`.

## Incluido

- login local por correo o teléfono;
- registro de un único perfil local;
- pantalla de bienvenida;
- gestor temporal de tareas;
- formulario, lista, resumen y progreso de tareas;
- Activities Java, layouts XML y navegación con Intent;
- widgets y contenedores exigidos por la evaluación;
- POO básica mediante modelo, Adapter y ViewHolder;
- repositorio Git y trabajo por fases.

El perfil permanece localmente. Las tareas solo existen en memoria durante la instancia de `TaskActivity` y no se restauran.

## Excluido

- base de datos, archivos, JSON, backend, API o red;
- autenticación real, múltiples usuarios o autologin;
- persistencia, edición o eliminación de tareas;
- arquitectura avanzada o contenidos de unidades posteriores;
- publicación o entrega sin autorización.

Este archivo explica el límite del MVP académico. No define IDs, versiones, algoritmos, claves ni mensajes.
